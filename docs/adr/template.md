## 배경과 요구사항
사용자가 해결하려는 문제, 로컬/클라우드 범위, 전원·동시성·개인정보 조건.

## 사실·가정·미확인
코드/공식 문서로 확인한 사실과 추정을 분리. 출처·확인 시점·조건을 적기.

## 검토한 대안
실제로 비교한 대안별 장점·제약·운영 비용·의존성을 기술. 평가하지 않은 항목을 평가했다고 쓰지 않기.

## 결정과 이유
무엇을 선택하고 무엇을 제외하는지, 요구사항과 연결해서 설명.

## 결과·비용·보안
단점, 무료 범위/과금 위험, 자격 증명, 최소 권한, 장애/백업/마이그레이션 영향.

## 검증·완료 기준
측정/테스트할 관찰 가능한 기준. 로컬/원격·예상/실제 결과 구분.

## 되돌리기·재검토 조건
무슨 신호가 나타나면 선택을 바꾸는지. 데이터 보존·전진 수정 또는 롤백 절차.

## 승인·변경 이력
실제 결정 확인을 기록. 미승인 상태를 Accepted로 표시하지 않기.
