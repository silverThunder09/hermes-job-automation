# 제품 범위: 셀프호스팅형 에이전트 채용 자동화 도구

## 목표와 현재 구현을 구분

목표는 사용자가 이력서를 한 번 비공개로 등록하고 조건·지원 정책을 설정하면, 자신의 PC가 꺼져 있어도 원격 실행 환경에서 공고 검색 → 회사 공식 정보 조사 → 사실 기반 문서 수정 → 판단 → 허용된 자동지원 → 결과 확인까지 수행하는 것입니다.

이 문서는 제품 방향을 설명합니다. 현재 코드에 모든 사이트의 브라우저 수집·무인 종단 지원이 완성됐다는 뜻이 아닙니다. 이 문서/규칙 PR에는 별도 작업 브랜치의 DB 전환 구현을 섞지 않습니다. main에 병합되지 않은 기능의 동작을 main에서 사용할 수 있다고 안내하지 않습니다.

## 배포 형태

- 공통 Python CLI/도구와 에이전트별 스킬/연결 설정으로 제공하는 셀프호스팅형 자동화 툴킷을 지향합니다. 설치형 GUI·다중 사용자 웹서비스·운영자 공유 계정은 필수가 아닙니다.
- 저장소/패키지 배포와 무인 실행 호스트는 다릅니다. PC가 꺼진 동안 실행하려면 다른 실행기/원격 에이전트가 필요하며 모델 인증·브라우저 세션·비공개 자료 접근을 그 환경에서 검증해야 합니다.
- 각 사용자는 자신의 DB/비공개 Storage·모델 인증·채용 계정을 설정합니다. 저장소 작성자의 Secret Key나 개인 지원 자료를 배포하지 않습니다.
- 기존 CLI 호출을 먼저 활용하고, 여러 에이전트의 공통 도구 연결에 실제 필요가 생기면 MCP를 별도 ADR로 검토합니다. 같은 스킬 파일을 복사하면 모든 에이전트에서 동일하게 동작한다고 가정하지 않습니다.
- GitHub 공개와 오픈소스 라이선스 선택은 별개입니다. 라이선스는 아직 확정하지 않았으며 이 문서로 MIT/Apache 등 특정 재사용 조건을 부여하지 않습니다.

## 실행과 책임

에이전트는 조사·비교·서술을 맡고, 코드는 저장 계약·사실/정책 검사·중복 지원 방지·실행 증빙을 책임집니다. 사용자 조건과 승인된 자동지원 정책을 통과한 경우에만 실제 제출하도록 설계합니다.

매 공고마다 무조건 사람에게 제출을 요구하는 것이 최종 목표는 아닙니다. 사전에 승인한 사이트·직무/지역 등 조건·금지 대상·지원 한도·유효 범위 안에서 자동 실행하고, 추가 인증·미확인 필수 답변·새 동의·범위 밖 작업·접수 결과 불명은 보류합니다. 사이트가 허용하는 자동화 범위를 확인하고 접근 통제는 우회하지 않습니다.

## 경량 운영 기록

기업용 온콜/SLA/상시 서비스 장애 보고서를 기본 요구하지 않습니다. 일반 개발 결함은 버그 이슈로 추적하고, 무인 실행 실패는 [실행·실패 기록](templates/run-failure.md)에 최소한으로 남깁니다. 개인정보 노출·잘못된 제출·데이터 손상 같은 실제 사고에만 영향·조치·재발 방지를 추가합니다.

공고/회사/실행 ID와 지원 결과·증빙은 필요한 비공개 저장소에 두고, 공개 이슈/PR에는 비밀 없는 요약만 남깁니다. 접수 결과 불명은 무조건 재시도하지 않습니다.
