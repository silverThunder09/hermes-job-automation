# 채용 플랫폼 접근 정책

정책 변경일: 2026-11-16. [ADR-0012](adr/0012-public-collection-policy.md)의 사용자 결정으로 명시적 허가 부재를 일괄 중지 사유로 삼던 규칙을 제거했습니다.

## 선택한 수집 경로와 기존 코드

[ADR-0011](adr/0011-private-collection-writer.md)에 따라 **사람인 공식 API 운영 경로는 폐기**했습니다. PC-on에는 로컬에서 클라우드 브라우저/MCP를 시작하고, PC-off에는 GitHub Actions가 클라우드 수집·기존 Supabase 저장을 실행하는 방향입니다. API 승인·키를 이 경로의 필수 조건으로 요구하지 않습니다. 기존 Python collector의 `manual_only`/`approval_required`는 새 클라우드 경로를 시험한 결과가 아닙니다. 기존 코드·설정은 아직 변경하지 않아 활성 API 설정이 있다면 기존 CLI가 호출할 수 있습니다.

실행 호스트, 사이트의 명시적 제한, 실제 접근 상태, 구현 여부, 사용자 승인 범위는 구분합니다. 공식 API가 없거나 기존 collector가 `manual_only`라는 사실만으로 선택한 브라우저 경로의 기술적 실패나 금지를 주장하지 않습니다.

## 현행 원칙

**명시적 허가 미확인만으로 중단하지 않는다.** 미확인은 허용 확정도 금지 확정도 아니다. 사용자 승인 범위의 공개·비로그인 공고를 소량·유한하게 검색·읽고, 최소 필요 항목과 출처·확인 시각을 기록할 수 있습니다. 관련 작업에 적용되는 명시적 제한과 실제 접근 상태는 아래 기준으로 별도 판정합니다. 공식 문의는 필수 선행 조건이 아니다. 문의 발송은 사용자 요청 없이 수행하지 않습니다.

## 진행·중단 기준

| 상황 | 판정 | 수행 범위·근거 |
|---|---|---|
| 명시적 허가 미확인만 있음 | 진행 가능 | 미확인과 적용 범위를 기록하고 기존 사용자 승인 내의 공개·최소 항목을 낮은 요청 빈도로 처리. 법적 허용 확정으로 보고하지 않음 |
| 적용되는 명시적 수집·복제 금지 또는 동의 요건 | 해당 작업 중단 | 정확한 출처·조항·대상·행위를 기록. API·기업회원 조항을 다른 브라우저·개인회원에게 전용하지 않음 |
| 대상 경로의 robots 제한 | 해당 경로 중단 | 실제 대상 경로·사용자 에이전트 그룹과 운영자 고지를 구분. 에이전트 위장이나 금지 경로·내부 엔드포인트 탐색으로 우회하지 않음 |
| 접근 차단·CAPTCHA·로그인·OTP 요구 | 중단 | 우회하거나 자동 재인증하지 않고 관찰한 상태를 기록. 인증이 필요한 작업은 별도 사용자 처리·승인 |
| 429·서버 오류·일시 접속 실패 | 중단·대기 | 요청을 늘려 해결하지 않음. 기술적 실패를 약관상 금지나 정상 검색 0건으로 바꾸지 않음 |

개인정보·이력서·비공개 자료, 공고 전문의 불필요한 복제·재배포, 사용자 승인 밖의 DB 쓰기로 확대하지 않습니다. 기존 DB 쓰기 승인·출처·검토 대기·정확한 재조회·중복 및 상태 보존 경계는 유지합니다. 에이전트 조사 결과를 `user_reviewed_manual`로 위장하지 않습니다. 외부 업로드와 운영 권한 변경은 각각 별도 승인이 필요합니다. 유료 자원·예약 가동 등은 [공통 승인 경계](../AGENTS.md#always-on-boundaries)를, 실제 지원은 [공고별 제출 승인](OPERATIONS.md#제출-승인)을 적용합니다.

## 플랫폼별 근거와 구현 상태

아래는 2026-11-16 공개 정책 조사 결과입니다. **명시적 허가를 못 찾았다는 이유의 일괄 중지 목록이 아니며**, 자동 수집기 활성화 표도 아닙니다. collector/검색→저장 통합의 미구현은 정책상 금지와 별도로 보고합니다.

| 플랫폼 | 확인된 근거 | 현재 판단의 범위 |
|---|---|---|
| 사람인 | 개인회원 제19조 제4항은 정보 복제·사용 제한. 자동화/API·DB 접근 금지는 기업회원 제23조 제3항 | 실제 작업에 적용되는 정보 이용 제한을 판정. 개인의 공개 소량 읽기까지 자동 금지로 확장하지 않음. 공식 API 경로는 계속 폐기 |
| 잡코리아 | 개인회원 제18조 제4항은 정보 복제 제한. API 약관에는 개인 사용·DB 수집 신청 제한 | 복제 작업과 API의 명시 조건을 구분. API 제한만으로 브라우저 검색을 금지하지 않음 |
| 원티드 | 개인회원 제19조 제7항은 사전 허락 없는 자동화 회원/게시물 수집 등을 제한 | 적용되는 수집 작업은 중단. 제2항의 상업적 사용·제3자 제공 제한을 개인 저장의 전면 금지로 바꾸지 않음 |
| 점핏 | 공식 홈의 이용약관이 사람인 약관으로 연결. 단건 원격 읽기 성공 | 적용되는 명시적 제한과 작업 범위를 기록. 검색·다건 수집→원격 저장 연결은 별도 미구현·미검증 |
| 직행 | 공개 약관에서 자동 수집·개인 DB 저장의 직접 규정은 미확인. robots의 공개 경로 허용과 일부 경로 제한 | 미확인만으로 차단하지 않고 현행 진행·중단 기준 적용. 허용 확정이나 수집기 구현 완료로 표현하지 않음 |
| 로켓펀치 | 공식 Open API가 공개 채용공고 조회·표시를 지원. 브라우저 /search 경로는 robots 제한 | API 요금·DB 보존 조건과 현행 일반 약관은 미확인. API 경로의 도입/키 발급과 비용 판단은 별도이며 브라우저 제한을 우회하지 않음 |
| 그룹바이 | robots의 운영자 고지는 검색·답변엔진 색인 외 브라우저 자동화·AI 에이전트 접근에 사전 서면 동의 요구 | 해당 자동접근은 중단. 일반 Allow:/를 별도 동의 요건 무시의 근거로 쓰지 않음 |

이 정책은 수집기·API 설정·writer·예약을 변경하거나 활성화하지 않습니다. [현재 구현 상태](../README.md#현재-프로젝트-상태)와 [운영 상태](OPERATIONS.md#예약과-재부팅)는 별도로 확인합니다. 과거 판단과 인용은 [사람인 조사 이력](SARAMIN_ACCESS.md)에서 보존하되 현행 판정은 이 문서를 우선합니다.

## 수동 공고 가져오기

브라우저에서 사용자가 직접 확인하고 지원 목적으로 관리할 공고만 JSON으로 저장합니다. 상세 공고 본문이나 기업의 비공개 정보는 불필요하게 복제하지 않습니다.

    [
      {
        "platform": "점핏",
        "platform_id": "example-id",
        "company": "회사명",
        "title": "공고명",
        "url": "https://example.com/job/example-id",
        "deadline": "2026-12-31",
        "location": "서울",
        "experience": "신입",
        "education": "학력무관",
        "employment_type": "정규직",
        "requirements": "사용자가 확인한 지원자격 요약",
        "source_kind": "user_reviewed_manual"
      }
    ]

실행 예:

    python -m hermes_job_automation.cli run --manual-file .\manual-postings.json
