# 채용 플랫폼 접근 정책

확인일: 2026-11-03 (사람인 인용 재확인: 2026-11-08)

## 선택한 수집 경로와 기존 코드

[ADR-0011](adr/0011-private-collection-writer.md)에 따라 **사람인 공식 API 운영 경로는 폐기**했습니다. PC-on에는 로컬에서 클라우드 브라우저/MCP를 시작하고, PC-off에는 GitHub Actions가 클라우드 수집·기존 Supabase 저장을 실행하는 방향입니다. API 승인·키를 이 경로의 필수 조건으로 요구하지 않습니다. 기존 Python collector의 `manual_only`/`approval_required`는 새 클라우드 경로를 시험한 결과가 아닙니다. 기존 코드·설정은 아직 변경하지 않아 활성 API 설정이 있다면 기존 CLI가 호출할 수 있습니다.

실행 호스트 결정과 플랫폼 허용은 별개입니다. 아래 표는 기존 접근 근거의 상태이며, 공식 API의 부재만으로 브라우저 읽기의 기술적 불가능을 주장하지 않습니다. 사용자 승인 범위의 조사, 반복 수집·저장, 로그인/제출을 구별하고 아직 확인되지 않은 허용을 만들어내지 않습니다.

이 프로젝트는 채용 사이트 이용약관과 사이트별 허용 범위 안에서만 자동 수집합니다. 플랫폼별 공식 허가가 없으면 브라우저 검색 화면을 반복 호출하거나, 내부 엔드포인트를 찾아내거나, CAPTCHA·로그인을 우회하지 않습니다.

| 플랫폼 | 자동 접근 상태 | 근거와 다음 단계 |
| --- | --- | --- |
| 사람인 | 공식 API 운영 경로 폐기, 브라우저 자동 수집 허용 미확인 | API 승인·키 발급을 이번 작업의 준비 조건으로 안내하지 않습니다. 개인회원 제19조 제4항은 정보 복제·사용·타인 제공을 제한하며, 명시적 자동화/API·DB 수집 금지는 기업회원 제23조 제3항입니다. 인용 정정이 브라우저 자동화 허가를 뜻하지 않습니다. |
| 잡코리아 | 자동 수집 중지 | API 이용약관은 개인 사용·프로젝트·DB 수집 목적의 신청을 승낙하지 않는다고 명시합니다. 구직용 브라우저 확인과 개인 지원 기록은 가능하지만 API 자동 수집은 연결하지 않습니다. |
| 원티드 | 자동 수집 중지 | 개인용 채용 API 또는 자동 접근 허용에 대한 공식 근거가 확인되지 않았습니다. |
| 점핏 | 자동 수집 중지 | 공식 API 및 자동 접근 권한이 확인되지 않았습니다. 공고 상세 페이지에서 접수 상태를 직접 검증해야 합니다. |
| 직행 | 자동 수집 중지 | 공식 API 및 자동 접근 허용에 대한 근거가 확인되지 않았습니다. |
| 로켓펀치 | 자동 수집 중지 | 공식 API 및 자동 접근 허용에 대한 근거가 확인되지 않았습니다. |
| 그룹바이 | 자동 수집 중지 | 공식 API 및 자동 접근 허용에 대한 근거가 확인되지 않았습니다. |

기존 사람인 API 코드에는 승인 플래그와 키 검사가 남아 있습니다. 이는 폐기한 경로의 기존 구현 설명일 뿐, API 신청·키 발급을 다시 요구하는 운영 지침이 아닙니다. 문서 결정만으로 기존 코드가 비활성화된 것은 아니므로 선택한 클라우드 경로와 혼용하지 않습니다.

과거 API 안내는 채용정보 검색용이며 브라우저 자동화·본인 이력서 접근·지원 제출 허가를 대신하지 않습니다. [사람인 단계별 근거·과거 API 비교·미발송 문의 초안](SARAMIN_ACCESS.md)을 참고하세요. 브라우저 우선 목표와 별개로 허용 범위가 확인되기 전에는 반복 수집/제출을 활성화하지 않습니다.

잡코리아는 채용정보 API가 공공기관·학교에 우선 제공되며, 공식 API 계약은 개인 사용과 데이터베이스 수집 목적의 이용신청을 허용하지 않습니다. 공개 웹페이지를 자동 복사하는 우회 구현도 포함하지 않았습니다.

## 공식 출처

- 사람인 개인회원 약관 (https://www.saramin.co.kr/zf_user/help/terms-of-service/person) — 제19조 제4항: 사전동의 없는 정보 복제·사용·타인 제공 제한
- 사람인 기업회원 약관 (https://www.saramin.co.kr/zf_user/help/terms-of-service/company) — 제23조 제3항: 사전 동의 없는 자동화/API·DB 접근·수집 금지. 모바일 통합 약관의 해당 문구를 개인회원 조항으로 귀속했던 오류를 정정하며, 개인용 자동화의 허용 여부는 별도 미확인
- 사람인 채용정보 API 이용안내 (https://oapi.saramin.co.kr/guide/info) — 사전 승인과 access-key, 일 500회 제한
- 사람인 채용공고 API 명세 (https://oapi.saramin.co.kr/guide/job-search)
- 잡코리아 API 안내 (https://www.jobkorea.co.kr/service/api)
- 잡코리아 채용정보 API 이용약관 (https://www.jobkorea.co.kr/network/Popup_Xml.asp) — 개인 사용·DB 수집 목적 신청 제한

## 수동 공고 가져오기

브라우저에서 사용자가 직접 확인하고 지원 목적으로 관리할 공고만 JSON으로 저장합니다. 상세 공고 본문이나 기업의 비공개 정보는 불필요하게 복제하지 않습니다.

    [
      {
        "platform": "점핏",
        "platform_id": "example-id",
        "company": "회사명",
        "title": "공고명",
        "url": "https://example.com/job/example-id",
        "deadline": "2026-12-31",
        "location": "서울",
        "experience": "신입",
        "education": "학력무관",
        "employment_type": "정규직",
        "requirements": "사용자가 확인한 지원자격 요약",
        "source_kind": "user_reviewed_manual"
      }
    ]

실행 예:

    python -m hermes_job_automation.cli run --manual-file .\manual-postings.json
