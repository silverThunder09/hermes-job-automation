# 사람인 접근 근거와 단계별 준비 — Issue #5

**현재 경로:** [ADR-0011](adr/0011-private-collection-writer.md)에서 사람인 공식 API 운영 경로를 폐기했습니다. 아래 API 안내·체크리스트·문의 초안은 과거 비교/조사 이력이며 현재 준비 지침이 아닙니다. 선택한 클라우드 브라우저/MCP 수집을 API 신청·키 발급으로 되돌리지 않습니다. 약관 인용과 브라우저/지원 접근 경계의 근거는 계속 보존합니다.

근거 확인일: 2026-11-08. 기존 공개 공식 자료의 읽기 전용 조사·보존본과 독립 재검증에서 다시 조회한 공개 공식 안내 페이지를 대조한 사실 정정이며, 법률 의견이나 플랫폼 승인서가 아닙니다. 재조회는 약관·API 명세·도움말 등 공개 안내 문서에 한정했으며, 계정 로그인·채용정보 API 호출·문의 발송·업로드·지원 제출은 하지 않았습니다.

**목표는 브라우저 우선의 지원 보조에서, 허용 범위와 사용자 승인을 확인한 자동 지원까지 나아가는 것입니다.** 수동 경로는 검증 대안이지 영구적인 제품 목표가 아닙니다. 다만 아래 자동 작업의 명시적 허가는 아직 확인되지 않았습니다. [현재 접근 정책](PLATFORM_ACCESS.md)의 조사/반복 수집/제출 경계는 유지합니다. 아래 내용은 당시 조사 기록이며 collector·설정·코드 변경이나 현재 운영 경로 승인을 대신하지 않습니다.

## 1. 약관 인용 정정과 공식 근거

- [개인회원 약관](https://www.saramin.co.kr/zf_user/help/terms-of-service/person) **제19조 제4항**:
  > 개인회원은 서비스를 이용하여 얻은 정보를 회사의 사전동의 없이 복사, 복제, 번역, 출판, 방송 기타의 방법으로 사용하거나 이를 타인에게 제공할 수 없습니다.
- [기업회원 약관](https://www.saramin.co.kr/zf_user/help/terms-of-service/company) **제23조 제3항 중 일부**:
  > 회사의 데이터베이스를 대상으로 회사의 명시적인 사전 동의없이 API 통신 등을 시도하거나 자동화된 수단(크롤링, 명령어 확장 등)을 활용하여 접근을 시도하는 행위 및 회사 데이터베이스에 수집된 정보의 전부 또는 일부를 수집하는 행위 등은 엄격히 금지됩니다.

[모바일 통합 약관](https://m.saramin.co.kr/index/clause)은 개인·기업 등 여러 약관을 함께 담습니다. 위 자동화/API·DB 문구는 **기업회원 조항**이며 개인회원 조항으로 인용하면 안 됩니다. 확인한 개인회원 원문에서는 `자동화된 수단`이라는 정확한 문구를 찾지 못했습니다. **이 인용 오류의 정정은 개인용 자동화의 허용 확인이 아닙니다.** 개인회원 제19조 제4항의 정보 이용 제한과 제19조 제5항 제7호의 서비스 운영 저해 제한도 고려해야 하며, 개인 구직 도구에 대한 적용·예외·사전 동의 절차는 공식 확인 대상입니다.

[API 이용안내](https://oapi.saramin.co.kr/guide/info)는 이용신청 승인 후 로그인, access-key 발급, **일 최대 500회 호출**을 안내합니다. 이는 공고 500개가 아니라 호출 수입니다. [공개 명세](https://oapi.saramin.co.kr/guide/job-search)의 기능은 채용정보 검색이며, 본인 이력서 조회나 지원 제출 권한의 근거가 아닙니다. **API 승인 ≠ 브라우저 자동화 승인 ≠ 이력서 접근/자동 지원 승인.** 개인 프로젝트의 승인 가능성도 실제 심사 전에는 확정하지 않습니다. API는 당시 비교했던 대안이며 현재 선택지에서는 폐기했습니다. 브라우저 우선 목표를 임의로 대체하지 않습니다.

[공식 지원 방법 안내](https://www.saramin.co.kr/zf_user/help/help-word/view?idx=365)는 다음을 구분합니다.

- **입사지원 / 채용 홈페이지**: 사람인 로그인 후 사람인 계정에 등록한 입사지원서로 진행.
- **홈페이지 지원**: 기업이 운영하는 별도 페이지에서 별도 방법으로 진행. 해당 사이트 규칙과 사용자 승인을 따로 확인해야 합니다.

이 안내는 지원 기능의 존재를 설명할 뿐 자동 조작·자동 제출을 허가하지 않습니다. 개인회원 제16조 제3항의 위탁/대행관리 시 작성 책임 조항 역시 자동 지원 허가가 아닙니다.

## 2. 작업별 확인 상태와 다음 관문

| 단계 | 확인한 사실 | 미확인 / 진행 조건 |
|---|---|---|
| 공개 공고 한 건 직접 열람 | 개인회원 제11조 제2항은 공고·기업정보 열람이 원칙적으로 무료라고 안내 | 현재 상세 공고의 브라우저 열람·DOM 읽기 성공은 미검증. 사용자의 직접 열람과 에이전트의 단건 자동 읽기·저장도 별개이며, 후자의 허용은 미확인 |
| 반복 검색·수집·DB 저장 | 개인회원의 정보 이용 제한과 기업회원의 명시적 자동화 제한을 구분해 확인 | 개인용 소량 수집 예외·빈도·건수·보존기간 미확인. 허가 전 반복 브라우저 수집기 연결 안 함 |
| 로그인 후 본인 이력서/지원 이력 읽기 | 계정의 지원서로 지원하는 기능 존재 | 계정 소유 ≠ 에이전트 접근 허가. 플랫폼 허용 범위와 사용자의 페이지별 읽기·저장 승인을 각각 확인; 로그인/개인자료 미시험 |
| 지원서 입력·첨부 보조 | 지원 기능의 존재만 확인 | 자동 입력·파일 선택 허용 미확인. 사용자가 최종 버튼을 눌러도 앞선 자동 조작 허가를 대신하지 않음 |
| 최종 제출 / 무인 반복 지원 | 온라인 제출 기능의 존재만 확인 | 사람 확인 후 에이전트 제출과 무인 제출을 따로 문의. 플랫폼 허용, 공고·서류·수신자별 사용자 승인, 중복 방지·완료 재조회 검증 필요. 아직 미실행 |

공개 읽기 가능·HTTP 200·로그인 성공·사용자 동의는 각각 자동 수집/제출 허가를 뜻하지 않습니다. 현재 대안은 **사용자가 고른 링크와 최소 직접 요약 → 로컬 적합도 검토·문서 초안 → 사용자 최종 검토·직접 제출**입니다. 이 대안도 공고 전문 복제나 모든 재이용을 포괄 허용하지 않습니다.

## 3. 당시 검토 체크리스트 — 현재 API 준비 지침 아님

- [ ] 원하는 단계를 선택하고 직무·지역·경력·제외 기업, 최소 기록 항목(URL/식별자·회사·제목·마감·직접 요약)을 정합니다. 앞 단계 동의를 뒤 단계로 확대하지 않습니다.
- [ ] 아래 문의를 사용자 선택으로 발송해 작업별 허용 범위·사전 동의 절차·빈도·보존 조건을 확인합니다. 답변의 날짜·담당 채널·허용 대상·조건을 보관합니다. 모호한 “API 가능” 답변은 브라우저 허가가 아닙니다.
- [ ] 로그인 단계가 별도 허용·승인되면 본인 계정·평소 로그인 방식·사용할 브라우저/프로필·읽어도 되는 페이지를 지정합니다. 가입·약관 동의·본인인증·CAPTCHA/OTP는 사용자가 공식 화면에서 직접 처리하며 우회하지 않습니다.
- [ ] 비밀번호·코드·쿠키·API 키를 채팅·저장소·로그로 보내지 않습니다. 공식 화면에서 직접 로그인하거나 지원 여부가 확인된 보안 금고를 이용합니다. 금고 연동과 브라우저 연결은 아직 검증하지 않았으며, 프로필/인증 파일 직접 읽기는 하지 않습니다.
- [ ] 본인 자료 읽기 전에 저장 위치·접근 권한·삭제 시점·외부 모델 전송 여부를 별도로 결정합니다. 이는 새 개인정보 정책 승인이나 현재 설정 변경이 아닙니다. 첫 계정 점검은 읽기 전용으로 제한하고 공개 조사 증거에 개인 서류를 섞지 않습니다.
- [ ] 입력/첨부가 허용되면 공고·지원 방식·이력서 버전·첨부·수신자·동의 항목을 검토합니다. 제출은 별도 승인 대상입니다. [이력서 노출 정책](https://www.saramin.co.kr/zf_user/help/privacy/privacy-policy)상 인재풀 연락처 비공개라도 입사지원 이력서에는 연락처가 공개됩니다.
- [ ] 제출 단계가 허용·승인되면 정확한 공고의 지원 이력/완료 상태로 결과를 재조회하도록 검증합니다. 시간 초과를 무조건 재시도하지 않고 중복 여부부터 확인합니다. 실제 지원 전에는 로컬 fixture로 검증하며 그 성공을 실사이트 허가/성공으로 보고하지 않습니다.
- [ ] API를 대안으로 선택할 때만 실제 이용목적을 기재해 승인받고 키를 발급합니다. [이용자 주의사항](https://oapi.saramin.co.kr/caution)의 키 공유·재판매 제한과 [출처 표시 안내](https://oapi.saramin.co.kr/introduce)를 확인합니다. API 신청/키 시험은 이번 작업에 포함하지 않습니다.

## 4. 공식 문의 초안 — 미발송

수신 후보: `help@saramin.co.kr` ([고객센터 안내](https://www.saramin.co.kr/zf_user/help/help-word/view?idx=365) 하단). API 대안 문의: `api@saramin.co.kr` ([API 안내](https://oapi.saramin.co.kr/guide/info)). 아래는 발송 권한이나 플랫폼 승인으로 취급하지 않습니다.

> 제목: 개인 구직 목적 브라우저 보조·자동 지원의 허용 범위 문의
>
> 본인 1인의 비상업적 구직을 위한 도구를 검토하고 있습니다. 접근통제 우회, 타인 개인정보 수집, 대량 DB 재판매는 하지 않습니다. 다음을 각각 허용하는지, 별도 사전 동의/계약과 공식 경로가 필요한지 알려주실 수 있을까요?
>
> 1. 사용자가 고른 공개 공고 한 건을 브라우저 DOM으로 읽고 URL·회사·제목·마감 등 최소 항목을 저장
> 2. 조건별 주기적 검색·수집(허용 빈도·건수·보존기간·출처 표시 조건 포함)
> 3. 사용자가 직접 로그인한 본인 계정의 이력서·지원 이력 읽기
> 4. 자기 지원서 입력·첨부 보조 후 사용자가 직접 최종 제출
> 5. 공고·문서별 사전 승인 후 에이전트 최종 제출, 그리고 별도의 무인 반복 지원
>
> 개인회원 제19조 제4항과 기업회원 제23조 제3항이 이 개인용 도구에 적용되는 범위와 예외/승인 절차도 확인 부탁드립니다. 브라우저 방식이 허용되지 않는다면 개인 프로젝트의 공식 API·제휴 대안이 있는지, 공고 검색/본인 자료 조회/지원 제출을 나누어 알려주시기 바랍니다. 요청량·보존기간은 허용 조건을 확인한 뒤 구체화하며, 허가 전 자동 수집·자동 지원을 시작하지 않겠습니다.

## 5. 조사 한계와 변경 경계

기존 조사에서 공개 공고 한 건 요청은 연결 재설정, 별도 브라우저 약관 열기는 도구 시간 초과로 끝났습니다. **이는 WAF·계약상 금지·기술적 불가능의 증거가 아닙니다.** 상세 DOM·계정 내 화면·지원 동작은 검증되지 않았습니다. 사용자의 브라우저를 임의 종료하거나 프로필을 변경하지 않으며, 연결 문제 해결도 자동화 허가와 별도입니다.

이번 정정은 보존된 공식 HTML/텍스트와 독립 재조회한 공개 공식 안내 문서의 URL·확인 시각·인용 위치를 대조했습니다. 공개 조사 원본과 검증 로그는 저장소 밖 임시 증거로 유지하고 개인 자료는 취급하지 않습니다. 실제 공고 재표본, 반복 요청, 내부 엔드포인트 탐색, 로그인, 문의/API 신청, 키 시험, 업로드, 제출은 수행하지 않았습니다. 접근 확대가 필요하면 별도 검토·결정·구현·검증을 거쳐야 하며 이 문서만으로 허용 상태가 바뀌지 않습니다.
